📦 Namespaces & Resources

  • Service: LoadBalancer:80
  • Pods: 2-4 (Nginx)
  • CPU: 100m quota
  • Memory: 128Mi quota
  • HPA: 75% CPU threshold
  • Access: Public HTTP

⚙️ Backend

  • Service: ClusterIP:5000
  • Pods: 2-5 (Flask)
  • CPU: 200m quota
  • Memory: 256Mi quota
  • HPA: 70% CPU threshold
  • Access: Frontend only

  • Service: Headless:5432
  • Pods: 1 (PostgreSQL)
  • CPU: 100m quota
  • Memory: 512Mi quota
  • Storage: 1Gi PVC
  • Access: Backend only

✅ Security & Design Summary

  • 🔒 Zero-Trust Networking: All traffic denied by default, explicitly allowed only
  • 📊 Resource Isolation: Hard quotas per namespace prevent resource exhaustion
  • 🔐 Least-Privilege RBAC: Each service account has minimal required permissions
  • 📈 Auto-Scaling Ready: HPA handles 2-10x baseline traffic spikes
  • 🛡️ High Availability: Pod Disruption Budgets ensure service continuity
  • 🏥 Self-Healing: Liveness/readiness probes with automatic pod restart
  • 📦 Multi-Namespace: 3 namespaces for frontend, backend, database isolation
  • ✓ Free Tier Optimized: Fits in t3.micro with headroom for peak load
